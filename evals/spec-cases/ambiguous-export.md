# 모호한 요청: 주문 목록 내보내기

평가용 가상 시나리오입니다. 실제 사용자 대화나 실행 기록이 아닙니다([설명](README.md)).

Status: 초안(사람 확인 전)

## 요청

"관리자 화면에서 주문 목록을 내보내기 할 수 있게 해줘"

## 저장소 맥락

- 관리자 화면에 주문 목록이 있고 날짜·상태 필터가 있다.
- 주문 API는 페이지 단위로 목록을 준다.
- 내보내기 기능은 아직 없다.

## 사용자 답

- 대상: 지금 필터가 적용된 주문 전체(현재 페이지만이 아님)
- 형식: CSV
- 그 밖의 질문: 알아서 정해 줘

## 기대 결과

- 물어야 할 것
  - 내보낼 대상이 필터 결과 전체인지, 보이는 페이지인지, 모든 주문인지
  - 파일 형식
- 들어가야 할 조건(필수)
  - 필터를 건 상태에서 내보내면 화면의 필터 결과 전체가 파일에 담긴다(여러 페이지 포함)
  - 파일을 열면 주문마다 한 행이 있고, 화면에 보이는 열과 같은 값이 들어 있다
  - 관리자가 아닌 사용자는 내보낼 수 없다
- 들어가면 안 되는 것
  - Excel·PDF 형식, 예약 내보내기, 이메일 발송
- 질문 상한: 3
