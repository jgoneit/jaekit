# 여러 구성요소 연결: 프로필 닉네임 저장

평가용 가상 시나리오입니다. 실제 사용자 대화나 실행 기록이 아닙니다([설명](README.md)).

Status: 초안(사람 확인 전)

## 요청

"프로필 화면에서 닉네임을 바꿔서 저장할 수 있게 해줘"

## 저장소 맥락

- 프로필 화면(프론트엔드)은 닉네임을 보여 주기만 한다.
- 사용자 API에는 조회만 있고 수정은 없다.
- 닉네임은 사용자 테이블에 저장된다.

## 사용자 답

- 중복 허용: 다른 사용자와 같은 닉네임은 허용하지 않는다
- 길이: 2–20자
- 그 밖의 질문: 알아서 정해 줘

## 기대 결과

- 물어야 할 것
  - 닉네임 중복을 허용할지
  - 길이나 문자 제한
- 들어가야 할 조건(필수)
  - **연동**: 사용자가 화면에서 닉네임을 바꿔 저장하면, 새로고침한 뒤 다시 조회해도 바뀐 닉네임이 나타난다
  - 이미 쓰이는 닉네임이나 길이 제한을 벗어난 닉네임은 저장되지 않고 이유가 화면에 표시된다
  - 다른 사용자의 닉네임은 바꿀 수 없다
  - **유지**: 닉네임 외의 프로필 정보는 바뀌지 않는다
- 들어가면 안 되는 것
  - 프로필 사진, 닉네임 변경 이력, 변경 횟수 제한
- 질문 상한: 3
