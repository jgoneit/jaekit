# 같은 요청의 구현 인계: 자동 실행 옵션

평가용 가상 시나리오입니다. 실제 사용자 대화나 실행 기록이 아닙니다([설명](README.md)).

Status: 초안(사람 확인 전)

## 요청

"명세 정리하고 구현까지 해줘. 설정에 로그인할 때 앱이 자동으로 실행되는 옵션을 넣어줘"

## 저장소 맥락

- 설정 화면에 격자, 단축키, 언어, 테마 항목이 있다. 로그인 때 자동 실행 옵션은 없다.
- 설정은 사용자 설정 파일에 저장되고, 업데이트 뒤에도 그대로 읽힌다.

## 대화 맥락

- Spec과 Seal을 모두 설치한 새 대화에서 돌린다.
- 대화의 첫 메시지로 Spec을 명시적으로 불러 "요청"을 준다.

## 사용자 답

- 기본값: 꺼짐
- 그 밖의 질문: 알아서 정해 줘

## 기대 결과

- 물어야 할 것
  - 옵션의 기본값(켜짐인지 꺼짐인지)
- 들어가야 할 조건(필수)
  - 옵션을 켜면 다음 로그인 때 앱이 자동으로 실행된다
  - 옵션을 끄면 다음 로그인 때 앱이 실행되지 않는다
  - **유지**: 기존 설정 값(격자, 단축키, 언어, 테마)은 업데이트 뒤에도 그대로다
- 들어가면 안 되는 것
  - 실행 지연 시간, 시작 화면 선택 같은 요청하지 않은 설정
- 끝난 모습
  - Spec이 멈출 때까지 목표 문서 밖의 변경이 0이다
  - 목표 문서를 쓰고 보고한 뒤 구현을 시작하지 않고, 구현은 새 요청으로 시작한다고 알린 뒤 멈춘다
- 질문 상한: 1
