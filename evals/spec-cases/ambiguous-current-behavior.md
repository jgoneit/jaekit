# 코드와 의도: 대소문자를 구분하는 검색

평가용 가상 시나리오입니다. 실제 사용자 대화나 실행 기록이 아닙니다([설명](README.md)).

Status: 초안(사람 확인 전)

## 요청

"상품 검색에서 이름 일부만 입력해도 찾을 수 있게 해줘"

## 저장소 맥락

- 상품 검색은 입력한 문자열이 상품명 전체와 정확히 같을 때만 결과를 준다(`src/search/match.ts`).
- 비교할 때 대소문자를 구분한다. 이 동작을 설명하는 문서, 테스트, 주석은 없다.

## 사용자 답

- 대소문자 구분: 의도가 아니었다. 구분하지 않는다
- 그 밖의 질문: 알아서 정해 줘

## 기대 결과

- 물어야 할 것
  - 대소문자를 구분하는 지금 동작이 의도인지. 코드와 문서로 정할 수 없고, 소문자로 입력했을 때 결과가 달라진다
- 묻지 않아야 할 것
  - 정확히 같을 때만 찾는 지금 동작을 유지할지. 요청이 바꾸라고 한 것이다
  - 비교를 어느 파일에서 할지 같은 구현 세부
- 들어가야 할 조건(필수)
  - 상품명의 일부만 입력해도 그 상품이 결과에 나온다
  - 대소문자가 달라도 같은 상품이 결과에 나온다
  - **유지**: 상품명 전체를 정확히 입력하면 지금처럼 그 상품이 결과에 나온다
- 들어가면 안 되는 것
  - 오타 교정, 검색 순위 조정, 자동 완성
- 끝난 모습
  - 지금 동작(정확히 일치, 대소문자 구분)이 근거 파일 경로와 함께 사실로 적혀 있다
- 질문 상한: 1
