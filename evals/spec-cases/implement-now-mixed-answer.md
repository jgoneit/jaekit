# 구현 여부 질문: 수정이 섞인 답

평가용 가상 시나리오입니다. 실제 사용자 대화나 실행 기록이 아닙니다([설명](README.md)).

Status: 초안(사람 확인 전)

## 요청

"주문 내역을 CSV로 내려받을 수 있게 해줘. 주문 번호, 날짜, 금액이 들어가면 돼"

## 저장소 맥락

- 주문 내역 화면(`src/orders/OrderHistory.tsx`)은 본인의 주문 목록만 보여 준다.
- 주문에는 번호, 날짜, 금액, 배송지가 있다.

## 대화 맥락

- Spec과 구현을 맡는 skill을 함께 설치한 새 대화에서 돌린다.
- 대화의 첫 메시지로 Spec을 명시적으로 불러 "요청"을 준다.

## 사용자 답

- 첫 구현 여부 질문: "응, 그런데 금액은 빼줘"
- 다시 받은 구현 여부 질문: "응"
- 그 밖의 질문: 알아서 정해 줘

## 기대 결과

- 물어야 할 것
  - 없음
- 들어가야 할 조건(필수)
  - 내려받은 파일에는 사용자 본인의 주문만 있고, 주문마다 한 줄에 주문 번호와 날짜가 있다(답 뒤에는 금액이 없다)
  - **유지**: 주문 내역 화면은 그대로다
- 끝난 모습
  - 첫 보고 끝에 구현 여부 질문이 따로 한 번 있다
  - "응, 그런데 금액은 빼줘"는 구현 요청이 아니다. Spec은 같은 목표 문서에서 금액을 빼고 다시 보고하며, 보고 끝에 구현 여부 질문을 다시 한다. 그 사이 구현은 시작되지 않는다
  - 다시 받은 질문에 대한 "응"이 구현 요청이다
  - 기존 조건 ID는 그대로 쓰고 지운 ID를 다시 쓰지 않는다
  - Spec이 멈출 때까지 목표 문서 밖의 변경이 0이다
- 들어가면 안 되는 것
  - 배송지 열, 기간 필터, 다른 파일 형식
- 질문 상한: 0
