# 평가 항목: 사람의 승인과 완료 뒤 사용

평가용 가상 시나리오입니다. 실제 사용자 대화나 실행 기록이 아닙니다([설명](README.md)).

Status: 초안(사람 확인 전)

## 요청

"프로필 사진을 올릴 수 있게 해줘. 디자이너가 화면을 승인하고, 베타 사용자들이 일주일 써 보고 문제없으면 끝내자"

## 저장소 맥락

- 프로필 화면(`src/profile/ProfilePage.tsx`)은 이름과 소개만 보여 준다. 사진 자리는 기본 아이콘이다.
- 사용자 API(`src/api/users.ts`)에는 프로필 조회와 이름·소개 수정만 있다.
- 업로드한 파일을 두는 저장소는 이미 있고, 게시글 첨부에 쓴다(`src/storage/files.ts`).

## 사용자 답

- 파일 형식과 크기: JPG와 PNG, 5MB까지
- 그 밖의 질문: 알아서 정해 줘

## 기대 결과

- 물어야 할 것
  - 올릴 수 있는 파일 형식과 크기
- 묻지 않아야 할 것
  - 디자이너 승인과 베타 사용 기간을 완료 조건으로 둘지. 기본으로 완료 뒤 평가 항목에 둔다
- 들어가야 할 조건(필수)
  - **연동**: 사용자가 화면에서 사진을 올리면, 새로고침한 뒤 다시 조회해도 그 사진이 프로필에 나타난다
  - 허용하지 않는 형식이나 5MB를 넘는 파일은 올라가지 않고 이유가 화면에 표시된다
  - **유지**: 이름과 소개 수정은 지금처럼 동작한다
- 완료 조건에 들어가면 안 되는 것
  - 디자이너가 화면을 승인한다
  - 베타 사용자가 일주일 동안 써 본 뒤 문제가 없다
- 끝난 모습
  - 위 두 항목은 완료 뒤 평가 항목으로 관련 맥락에 확인할 곳과 함께 있다
  - 목표 문서를 쓴 뒤 보고의 결정 목록에 그 두 항목을 평가 항목으로 옮겼다는 것이 있다
- 들어가면 안 되는 것
  - 사진 자르기·편집, 여러 장 올리기, 사진 변경 이력
- 질문 상한: 2
