Jaekit v0.1.6은 Core `ha 0.1.6`, Spec `0.1.12`, Seal `0.1.17` 조합입니다. macOS·Linux의 arm64·amd64를 지원합니다. 이번 릴리스에도 Windows 파일은 없습니다.

이번 변경:

- README를 새로 구성했습니다. Jaekit이 도움이 되는 경우, 환경별로 쓸 수 있는 Spec·Seal과 설치 방법, Windows 사용자 안내, `ha`와 두 플러그인의 업데이트 명령을 담고 문단을 짧게 나눴습니다. README의 설치·업데이트 명령은 설치 안내의 같은 단계 명령과 같은지 시험으로 확인합니다.
- Seal 0.1.17은 `run-rules/4` 재개 창이 이어받는 횟수 상한을 다시 적지 않고 [실행 기록 계약 §4.7](https://github.com/jgoneit/jaekit/blob/v0.1.6/contracts/run-record.md#47-run-rules4)로 연결합니다. 이전 요약에는 인용으로 정한 마지막 상한 뒤의 감액도 반영한다는 계약의 조건이 빠져 있었습니다. `/3`의 재개 상한을 설명하는 문장도 `/4`는 §4.7을 따르도록 연결합니다.
- 상태 JSON 계약의 `runs_limit`이 `/4` 창의 값을 밝히고, 이어받은 상한보다 낮춘 `/4` 재개를 행동 시나리오로 확인합니다.

Core의 동작은 v0.1.5와 같습니다. 기본 규칙은 `/3`이며 Seal은 새 목표를 계속 `run-rules/4`로 시작합니다. 기존 `/1`·`/2`·`/3`·`/4` 목표는 저장된 규칙·사용량·시간 한도를 유지합니다.

[설치·업데이트 안내](https://github.com/jgoneit/jaekit/blob/v0.1.6/guides/INSTALL.md)에 따라 Core와 플러그인을 함께 갱신합니다. Codex marketplace는 `jgoneit/jaekit@v0.1.6`, Claude Code marketplace는 `jgoneit/jaekit#v0.1.6`에 고정합니다. 현재 PATH의 실제 실행 파일과 새 호스트 세션의 Skill 출처를 확인하세요.

첨부한 `ha_0.1.6_<os>_<arch>.tar.gz` 네 파일과 `checksums.txt`를 함께 사용합니다. 아카이브에는 실행 파일·라이선스·공개 문서·참조 검사 예시가 포함됩니다. Homebrew 설치의 지원 파일은 `$(brew --prefix jaekit)/share/jaekit`에 있습니다. 참조 검사는 Python 3 표준 라이브러리를 사용하는 선택 사항이며, Python이나 특정 시험 러너가 Core·Spec·Seal 전체의 필수 조건은 아닙니다.

배포 검증은 네 플랫폼 빌드, 실행 파일 형식, 아카이브 내용과 체크섬을 확인하고 Linux amd64에서 압축한 Core와 참조 검사를 실행합니다. 다른 플랫폼의 빌드 성공을 해당 플랫폼의 실제 실행 결과로 대신하지 않으며, Codex·Claude의 실제 모델 수행을 보증하지 않습니다. Windows CI의 결과는 현재 소스의 로컬 후보에 대한 것이며 이번 릴리스의 Windows 지원을 뜻하지 않습니다.
