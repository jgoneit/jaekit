# 검증 근거와 실제 관측의 연결

아래는 가상 형식 예시이며 실제 수행 기록이 아니다. 셸과 모델 어댑터를 잇는 가상의 제품을 설명한다. `review-v1`은 `code-v1`·`check-v1`에 관한 검토다. 코드와 검사를 바꾼 셸에는 `review-v2`를 연결하며 예전 검토를 재사용하지 않는다.

기대 근거는 합의한 실행 의미와 공개 응답 계약이다. 실제 프로그램 실행 사실 자체가 올바름의 근거가 되지 않는다. Bash 프로세스의 제어된 입력 관측과 fake 모델 어댑터 관측은 서로 다른 경계다. real model은 둘 다 미관측이며 fake의 성공을 실제 모델 계약의 성공으로 확대하지 않는다.

## 관측 비교
| 대상 | 기대 근거 | 코드 | 검사 | 검토 | 관측 경계 | 대체 환경 | 미관측 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| shell-v1 | 합의한 실행 의미 | code-v1 | check-v1 | review-v1 | Bash process | 없음 | Zsh, real model |
| model-v1 | 공개 응답 계약 | code-v1 | check-v1 | review-v1 | adapter output | fake model | real model |
| shell-v2 | 합의한 실행 의미 | code-v2 | check-v2 | review-v2 | Bash process | 없음 | Zsh, real model |

예정은 두 셸과 실제 모델 비교였으나, 가상 보고가 설명하는 관측은 표의 경계뿐이다. 시각은 가상 설명에서도 알려진 사건·작성 출처를 구별해야 하며 이 예시는 실제 시각이나 실행 기록을 제공하지 않는다. 완전한 실행·호스트 관찰 사례로 인용할 수 없다.
